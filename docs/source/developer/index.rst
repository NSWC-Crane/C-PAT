Developer Guide
===============================

.. meta::
  :description: Developing and contributing to C-PAT.

These pages describe how C-PAT is built and how to change it. They are for people working on the API, the web client, the database, or this documentation. Deploying and operating C-PAT is covered in :ref:`installation-index`, using the application in :ref:`user-index`, and administering it in :ref:`admin-index`.

* **Learn by doing.** :ref:`developer-getting-started` takes you from a clean machine to a running local instance with passing tests.
* **Get a task done.** The how-to pages give the steps for the changes you make most often: :ref:`developer-add-an-endpoint`, :ref:`developer-add-a-page`, :ref:`developer-add-a-migration`, and :ref:`developer-add-an-environment-variable`. :ref:`developer-debugging` and :ref:`developer-contributing` are task pages too.
* **Look something up.** :ref:`developer-api-reference`, :ref:`developer-coding-standards`, :ref:`developer-testing`, :ref:`developer-release-process`, :ref:`developer-dependencies`, and the :ref:`developer-glossary`.
* **Understand why.** :ref:`developer-architecture`, the :ref:`developer-backend` and :ref:`developer-frontend` guides, :ref:`developer-database`, and the :ref:`developer-decisions`.

If you are new to the project, read :ref:`developer-getting-started`, then :ref:`developer-architecture`, then :ref:`developer-contributing`.
